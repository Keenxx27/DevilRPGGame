# 第一章教室场景设计

## 目标

在 `Assets/Scenes/SampleScene.unity` 中搭建一个可识别的俯视 2D 教室，用于第一章试玩开场。场景只承担空间表达，不包含美术精修、碰撞或交互。

## 视角与范围

- 保留正交 2D 摄像机，将其置于教室中心附近并调整尺寸，使教室主体完整可见。
- 教室空间约为宽 16、高 10 个 Unity 单位，前方位于画面上侧。
- 保留现有 `Main Character`、`Professor`、`Global Light 2D` 和移动脚本。

## 静态布局

- 浅色地面覆盖教室主体，四周用深色几何物件表示墙体。
- 上侧中央放置黑板；黑板前放置讲台和教师桌。
- `Professor` 移至黑板与教师桌附近。
- 中央设置三列、四排学生桌椅，并保留清晰的纵向与横向走道。
- `Main Character` 移至一个学生座位旁，进入 Play 模式后仍可使用 WASD 移动。
- 左侧设置三扇窗户；右下侧设置教室门；右上侧设置储物柜。

## 表现方式

- 不引入外部图片或美术包。
- 复用当前项目已有的圆形占位 Sprite，通过位置、缩放和颜色形成地面、墙体、黑板、桌椅、窗户、门和柜子。
- 使用清楚的命名与父子层级组织静态物件：

```text
Classroom
├── Floor
├── Walls
├── Blackboard
├── Teacher Area
├── Student Desks
├── Windows
├── Door
└── Storage Cabinet
```

- 地面排序层最低，固定设施其次，家具居中，角色排序最高，避免相互遮挡。

## 范围边界

- 不添加 `Rigidbody2D`、`Collider2D` 或寻路组件。
- 不实现桌椅碰撞、开门、对话、上课动画、镜头跟随或场景切换。
- 不新增运行时场景生成脚本；所有教室物件直接序列化进场景。

## 验证标准

- 场景层级包含教室根对象及上述八类静态区域。
- 黑板、讲台、教师桌、十二套学生桌椅、三扇窗户、一扇门和一个储物柜均存在。
- `Professor` 位于教室前方，`Main Character` 位于学生区域。
- 摄像机能覆盖教室主体，物件排序不会遮挡角色。
- 原有 `MainCharacterMovement` 组件和默认速度 5 保持不变。
- 场景未新增物理或交互组件。
