# 市政隔离执行人员角色视觉设计

## 目标

为公寓对峙剧情中的两名猎魔机构市政隔离执行人员制作透明背景的 2D 俯视硬像素角色素材，使其体现制度化、可强制执行的压迫感，而非战斗猎魔人的武装感。

## 共同规范

- 透明背景、2D 俯视 RPG 硬像素风，左右朝向独立绘制。
- 主色为深灰与冷蓝灰；证件带或袖章用一抹暗红点明机构属性。
- 体型均略小于林健太：A 偏高瘦，B 略矮但动作干练。
- 每人均具四向站立与四向两帧行走。
- 不配外露武器；机构压迫感来自编号牌、证件、终端和封存用具。

## A：文书执行人员

- 瘦高的中年男性，短而整齐的深灰发，神情冷淡。
- 灰蓝立领制式长外套，白衬衫、窄领带、黑色长裤和皮鞋。
- 胸前编号牌，腰侧便携终端；随身携带米白色隔离通知。
- 除基础动作外，增加一张正面“递出隔离通知”动作：右手将文件伸向前方，通知正面清晰但不含可读文字。

## B：现场执行人员

- 利落的成年女性，短发或低盘发。
- 深灰短制式外套、深色长裤、短靴，胸前编号牌。
- 腰侧封存袋和便携终端；无外露武器。
- 在剧情中站在 A 的侧后方，承担观察、压场与随时执行隔离的视觉职责。

## 接入边界

- 角色服务于公寓对峙剧情，不扩展新的战斗、追逐或交互机制。
- A 的递出通知动作仅用于对峙演出；普通移动状态只使用站立和行走动作。
- 视觉子对象承载 Animator 与 SpriteRenderer，根对象保留既有剧情定位与碰撞设置。

## 验收标准

- 两名角色能一眼看出属于同一市政隔离执行体系，且与普通学校行政人员区分明显。
- A 的通知动作清晰、正面、文件朝向主角。
- B 不抢夺 A 的文书视觉焦点。
- 两人左右向均非镜像复用，透明背景无底板或阴影。
