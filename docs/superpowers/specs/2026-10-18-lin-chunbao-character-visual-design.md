# 林春宝角色外观设计

## 目标

为林春宝制作与林健太统一规格的 2D 俯视像素角色素材。她应呈现为一名约十六岁的活跃女学生与校内搏击社社长；轮廓、颜色和动作需与林健太偏暗、朴素的形象清楚区分。

## 外观

- 深棕色头发，肩部附近的松散马尾；马尾以低调发圈收束。
- 蓝绿色、略宽松的训练短袖；不添加搏击社徽记。
- 深色运动长裤与轻便运动鞋，保留学生的日常感。
- 单侧暖红色或橙红色腕带，作为唯一明显的搏击社习惯细节。
- 默认表情为简单、轻微上扬的嘴角；不制作额外的夸张表情差分。
- 使用与林健太一致的修长学生头身比例，但角色本体视觉高度约为林健太的九成，体现她略矮于哥哥的设定。

## 姿态与动画

- 单帧规格为 48×64 像素，沿用林健太的大头、修长比例与透明背景规范。
- 提供正面、背面、左向、右向四个站立姿态。
- 提供上、下、左、右四向行走动画；每个方向两帧。
- 行走仅表现腿部交替、手臂小幅摆动和马尾轻微摆动；不加入战斗待机或格斗动作。
- 虽无林健太面部侵蚀一类的强不对称特征，左右朝向仍制作独立姿态，不通过运行时镜像替代。

## 色彩与辨识

- 蓝绿色上衣在整体明度上高于林健太的近黑色连帽衫。
- 暖红腕带只作局部点缀，避免盖过蓝绿色上衣和深棕马尾形成的主体轮廓。
- 像素密度、描边与阴影层级与林健太角色素材保持一致。

## 非目标

- 不为本轮制作战斗姿势、攻击特效或表情动画。
- 不添加社团标志、护具或夸张格斗装备。
