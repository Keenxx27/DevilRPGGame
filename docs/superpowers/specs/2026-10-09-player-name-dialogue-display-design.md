# 玩家姓名在对话框中的显示

## 目标

玩家在起名界面确认的名字，应替代所有由主角说出的对白中的“主角”显示名。

## 设计

`PlayerChosenName` 保存玩家是否已确认有效名称及其值。对话系统在将角色名写入 `DialogueHUD` 前，若原始角色名恰为“主角”且玩家已确认有效名称，则显示该值；否则仍显示“主角”。其余角色名保持原样。

此规则同时覆盖普通对话与带选项的锁定对话。剧情页面中的角色标识不修改，从而不影响既有剧情、分支或场景配置。

## 边界与验证

- 尚未确认自定义姓名时，主角对白显示“主角”。
- 确认普通自定义姓名后，主角对白显示该姓名。
- 输入“林健太”触发“真正的名字”彩蛋后，主角对白显示“林健太”。
- 非主角角色名不被替换。
- 编辑模式测试覆盖上述三种情况。
