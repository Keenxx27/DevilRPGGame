# 教授角色视觉设计

## 目标

为教室中的 `Professor` 制作一套可用于四向站立与四向行走的 2D 俯视像素角色素材。角色应在学生群体中一眼可辨，同时呈现克制而有压迫感的学院派讲师形象。

## 人物外观

- 老年男性，灰白短发，头发整齐向后梳理；不留胡须。
- 佩戴细框眼镜。
- 眉眼略压低、嘴线平直，不使用夸张的愤怒表情。
- 身体站姿笔挺；压迫感主要来自端正姿态、深色轮廓与正式着装。

## 服饰与配色

- 炭灰色西装外套。
- 白色衬衫，暗红色领带。
- 深灰色西裤、黑色皮鞋。
- 整体维持低饱和、沉稳的色调，与林健太的近黑连帽衫及林春宝较亮的学生运动装形成清晰区分。

## 精灵规格

- 风格：透明背景、2D 俯视 RPG 硬像素风，清晰像素边缘，不采用平滑、手绘或写实渲染。
- 布局：192×192 像素角色表，4 列×3 行；每格 48×64 像素。
- 第一行依次为：正对屏幕、背对屏幕、朝屏幕右侧、朝屏幕左侧的站立姿态。
- 第二、三行依次为：向下、向上、向右、向左行走的两帧动画。四个方向独立绘制，不以镜像替代。
- 行走时仅让双腿、外套下摆和领带轻微摆动；不加入夸张姿势或表情变化。
- 人物采用与林健太一致的大头紧凑角色构图；视觉高度略高于林健太，以传达成年人身份，但保持同一场景的可读性与碰撞基准。

## 场景接入边界

- 初始接入位置为 `Assets/Scenes/SchoolClassroom.unity` 的 `Professor`。
- 保留教授已有的课堂广播、移动/剧情引用、位置、父级及交互逻辑；美术接入只替换可见角色表现。
- 行走状态由教授现有或后续的位移逻辑驱动；如果场景当前没有实际位移，则待下课离场逻辑触发时自动使用对应方向的行走动画。

## 验收标准

- 角色在教室中显示为灰白头发、深色西装、白衬衫、暗红领带的老年男性教授，无胡须。
- 四个站立朝向与四个两帧行走朝向完整存在，且透明背景、像素边缘和尺寸规范一致。
- 教授视觉高度略高于林健太，且未遮挡课堂静物层级。
- 保留所有教授既有剧情与移动引用，场景可无 C# 编译错误打开。
