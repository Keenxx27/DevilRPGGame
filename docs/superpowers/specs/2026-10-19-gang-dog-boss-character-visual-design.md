# 丧家犬老大角色视觉设计

## 目标

为瓦砾堆追逐战中的 `GangDogBoss` 制作完整的 2D 俯视 RPG 硬像素角色素材，使其作为强壮的普通中年人类具备压迫感，并清晰表达追逐、拔刀冲刺与撞墙硬直。

## 外观

- 四十岁上下的强壮普通人类男性，不含恶魔肢体、侵蚀纹路或超自然特征。
- 比林健太视觉高约 10%～15%，宽肩、略短腿，体态沉重前倾。
- 杂乱深色短发、短而未完全修整的胡茬；一侧眉峰只有一道浅暗红褐色旧伤，不延伸至脸颊。
- 磨旧暗灰褐工装夹克，内搭脏灰或墨绿背心；深棕耐磨工作裤（膝盖补片）和厚底旧工靴。
- 腰间旧帆布工具袋露出钳子、碎骨片或小瓶，袋上有一条褪色橙色绑带。
- 右手持有带旧划痕、无夸张血迹的实用短猎刀。

## 动作

- 四向独立站立：右手持刀下垂。
- 四向独立行走，每方向两帧；工装下摆、工具袋和刀手有轻微摆动。
- 四向独立拔刀冲刺，每方向两帧；右臂前探、刀尖前指，符合 `GangDogBoss` 的准备后冲刺。
- 四向撞墙硬直，每方向一帧；右手带刀下垂或撑腿，左手捂额头。
- 所有动作均为透明背景、硬像素、2D 俯视 RPG 风格，不镜像代替左右方向。

## 接入边界

- 保留 `GangDogBoss` 的 Rigidbody2D、Collider2D、移动/冲刺/硬直/抓捕逻辑和 `RubbleBossEncounter` 引用。
- 新增视觉子对象接收 Animator；根对象继续负责物理与 AI 位移。
- 视觉控制器按现有状态时序显示：普通追逐使用行走，`prepareTime`/`chargeTime` 使用冲刺，`stunTime` 使用硬直。
