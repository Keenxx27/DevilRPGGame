# 十三角色外观设计

## 目标

为恶魔十三制作 2D 俯视硬边像素角色素材。它在初见时应被误认成小黑猫，只有在细看时才通过眼睛、耳朵和尾焰显露出非猫的身份。

## 外观

- 体型遵循现实成年家猫的比例；静坐高度约到主角小腿中下段，不采用幼体化短腿比例。
- 通体为近乎吸光的漆黑短毛，仅用极少深蓝灰边缘像素勾勒轮廓。
- 眼睛为明亮蓝色的圆瞳，有细密、复杂的虹膜层次；不用猫的竖瞳。
- 耳朵整体为猫耳轮廓，耳内为略半透明的薄膜结构，可轻微转动偏向声音来源。
- 尾巴保持正常家猫长度与比例；尾尖始终有一小簇冰蓝色、绒状的火焰。

## 姿态与动画

- 遵循角色统一的四个静止方向与四向行走动画规格。
- 下、上、左、右四种静止姿态全部为坐姿，呈现安静、好奇地观察环境的状态。
- 上、下、左、右四向行走改为四足低重心小跑；每个方向使用两帧。
- 行走帧只表现轻微的四肢交替、薄膜耳偏转与冰蓝尾焰摆动，不添加战斗动作。
- 左右方向均为独立绘制，不依赖运行时镜像。

## 画面规范

- 使用与林健太、林春宝一致的 2D 俯视硬边像素风、透明背景和有限色阶处理。
- 黑色身体避免成为纯黑色空洞：只允许在轮廓边缘与毛发转折处使用极少深蓝灰色像素。
- 蓝色圆瞳与冰蓝尾焰是黑色身体上最明显的两处高亮，并与荧光蘑菇场景的蓝光呼应。

## 非目标

- 不做战斗、攻击、受伤或表情差分。
- 不将耳朵画成鱼鳍、尖锐耳翼或其他远离猫耳轮廓的形态。
